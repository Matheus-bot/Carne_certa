# 🥩 CarneCerta

Sistema inteligente para recomendação de carnes em açougues.

---

#  Sobre o Projeto

O CarneCerta é uma plataforma digital criada para ajudar clientes a escolherem a carne ideal de forma rápida, intuitiva e inteligente.

A proposta surgiu da dificuldade que muitas pessoas possuem ao escolher cortes de carne no açougue.

O sistema recomendará carnes com base em:

* tipo de preparo
* maciez
* gordura
* custo-benefício
* quantidade de pessoas
* preferência do usuário

Além disso, o projeto possui foco em:

* acessibilidade
* experiência do usuário (UX)
* interface moderna
* inteligência de recomendação
* praticidade no atendimento
